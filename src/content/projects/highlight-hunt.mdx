## The problem

Most memory games stay flat. This one keeps getting harder, so players stay in the zone.

## Approach

- Progressive grid difficulty: 3 x 3, then 4 x 4, then 5 x 5
- Quick-flash patterns with real-time score tracking
- A global leaderboard
- The OpenAI API analyses each run: correct highlights, accuracy, completion time and score
